📖 Voice Commands Cheat Sheet
💡 Say "Sanchalan" before a command. While dictation is active, "stop dictation" works without the wake word.
Tabs & Navigation
  • "Sanchalan, next tab"
  • "Sanchalan, previous tab"
  • "Sanchalan, switch to tab 3"
  • "Sanchalan, switch tab GitHub"
  • "Sanchalan, switch time YouTube"
  • "Sanchalan, choose 1" (for ambiguous matches)
Gaze Text Selection (Copy & Cut)
  • "Sanchalan, start copy"
  • ↳ Move gaze to the ending text
  • "Sanchalan, end copy"
  • "Sanchalan, start cut"
  • ↳ Move gaze to the ending text
  • "Sanchalan, end cut"
  • "Sanchalan, confirm cut"
  • "Sanchalan, cancel selection"
Web Navigation & Search
  • "Sanchalan, open WhatsApp"
  • "Sanchalan, search for "
  • "Sanchalan, open YouTube"
  • "Sanchalan, search in YouTube "
Browser Actions
  • "Sanchalan, new tab"
  • "Sanchalan, reload tab"
  • "Sanchalan, go back"
  • "Sanchalan, go forward"
  • "Sanchalan, close tab" (asks confirmation)
Dictation (Voice Typing)
  • "Sanchalan, start dictation"
  • "Stop dictation" (or "stop typing")
Editing & Clipboard
  • "Sanchalan, copy selected text"
  • "Sanchalan, cut selected text" (asks confirmation)
  • "Sanchalan, paste"
  • "Sanchalan, select all"
  • "Sanchalan, undo" / "redo"
